# Layrix

**Отдельный менеджер зон для Windows — без установки всего PowerToys.**

[English](README.md) · [Скачать](https://github.com/salvrave001/Layrix/releases/latest)

Независимая альтернатива для тех, кому нужен сценарий работы с окнами, похожий на FancyZones. Проект не связан с Microsoft или PowerToys.

## Возможности

- Зажмите клавишу привязки (**Shift** по умолчанию) при перетаскивании окна: появятся зоны. Отпустите мышь, чтобы разместить окно.
- Дополнительный модификатор (**Ctrl** по умолчанию) — объединение нескольких зон на одном мониторе.
- **Win + ← / →** — перемещение активного окна между зонами.
- Наглядное редактирование прямо поверх рабочего стола: создание, перемещение, изменение размеров и разделение зон.
- Совместное изменение соседних границ.
- Отдельные раскладки для мониторов, готовые шаблоны и собственные макеты.
- Стеклянный интерфейс WinUI, тёмные кнопки и значок настроек-шестерёнка.
- Режимы отображения зон: невидимые, поверх окон при перетаскивании или на рабочем столе.
- Автозапуск с Windows, работа в трее.
- Настраиваемые клавиша привязки, цвет зон и акцент приложения (по умолчанию — акцент Windows).

## Установка

1. Скачайте `Layrix-1.0.3-windows-x64.zip` из [Releases](https://github.com/salvrave001/Layrix/releases).
2. Распакуйте архив целиком в папку, доступную для записи.
3. Запустите `Layrix.exe`. Откроется редактор; программа также останется в трее. Автозапуск с Windows оставляет только значок в трее.

Не удаляйте соседние DLL и языковые папки: они нужны для работы приложения. Архив включает Windows App SDK и библиотеки Visual C++.

Требования: Windows 10 1809 или новее / Windows 11, **x64**. Сборок для x86 и ARM64 нет. Первый релиз не подписан цифровой подписью. Контрольная сумма архива находится в `SHA256SUMS.txt`.

## Как редактировать зоны

Нажмите карандаш у макета. Галерея скроется; зоны появятся поверх выбранного монитора в реальном размере. Тяните зоны и их границы мышью. Создавайте зоны на свободном месте или кнопкой «+ Зона».

**Сохранить / Ctrl + S** применяет изменения. **Esc** отменяет. При изменении встроенного шаблона создаётся собственный макет.

## Настройки и обновление

Настройки открываются шестерёнкой в шапке редактора или из меню трея. Автозапуск выключен по умолчанию. После его включения Layrix запускается при входе в вашу учётную запись без открытия редактора. Можно сменить клавишу привязки, режим отображения зон и цвета подсветки.

Макеты и настройки хранятся в `layouts.json` рядом с программой. При обновлении перенесите этот файл в папку новой версии. Перед переносом программы отключите автозапуск, а затем включите его из новой папки.

Начиная с версии 1.0.1 автозапуск использует ярлык `Layrix.lnk` в папке «Автозагрузка» текущего пользователя. Старая запись переносится автоматически при запуске обновлённого EXE по тому же пути. При недоступности трея значок создаётся повторно. Журнал запуска находится в `%LOCALAPPDATA%\Layrix\logs\startup.log`.

Окна с повышенными правами могут пропускаться. Некоторые приложения ограничивают минимальные размеры окон. Импорта настроек FancyZones и всех функций PowerToys в этом релизе нет. Не включайте одновременно одинаковые горячие клавиши в нескольких менеджерах окон.

## Сборка и лицензия

Инструкция сборки приведена в [README.md](README.md#build). Для сообщений об ошибках укажите версию Windows, масштаб экрана и конфигурацию мониторов. Не прикладывайте непроверенные скриншоты рабочего стола с личными данными.
