# Layrix 1.0.1 — startup reliability

This update addresses startup registration and notification-area initialization problems reported after reboot.

- Startup now uses a standard shortcut in the current user's Windows Startup folder. The shortcut contains the executable path, working directory, and `--startup` argument.
- Existing v1.0.0 Run registrations for the same executable are automatically migrated after launching the updated version. The old Run value is removed only after the shortcut is saved.
- An automatic launch no longer opens the editor if Layrix is already running.
- If Explorer is not ready to accept the tray icon, Layrix retries every two seconds. It also restores its icon after the taskbar is recreated.
- Startup diagnostics are written to `%LOCALAPPDATA%\Layrix\logs\startup.log`.

Close Layrix before replacing its files. If upgrading into a different folder, disable startup from the old version, then enable it in the new version. Check the Startup switch in Settings after updating. A full Windows reboot is a user-side verification step; it is not performed by the app's automated tests.

The archive includes Windows App SDK and Visual C++ runtime DLLs. Extract it completely and keep the files together.

Исправления автозапуска: ярлык с правильной рабочей папкой, автоматический перенос старой записи для той же копии программы, повторное создание значка трея и восстановление после перезапуска панели задач.

После обновления проверьте переключатель автозапуска в настройках. Журнал запуска: `%LOCALAPPDATA%\Layrix\logs\startup.log`. Для окончательной проверки выйдите из Windows и войдите снова либо перезагрузите ПК самостоятельно.
