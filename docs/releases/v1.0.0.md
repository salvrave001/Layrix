# Layrix 1.0.0

First public release of Layrix: a standalone zone-based window manager for Windows, offering a FancyZones-style workflow without installing the full PowerToys suite.

## Included

- Shift-drag snapping; Shift + Ctrl for multiple zones.
- Win + Left / Right navigation between zones.
- Per-monitor layouts and custom layouts.
- Desktop zone editing with shared-border resizing, splitting, moving, adding, and removing zones.
- Dark WinUI editor and floating toolbar.
- Highlight colors, spacing, and optional startup with Windows.

## Installation

Download **Layrix-1.0.0-windows-x64.zip**, verify it against **SHA256SUMS.txt**, extract the entire archive, and run **Layrix.exe**. The application starts in the tray. Double-click its icon to open the editor.

Windows 10 1809 or later / Windows 11, x64. Runtime DLLs are included. Keep all files together in a writable folder. The interface is currently Russian. The executable is unsigned.

For upgrades, back up `layouts.json`. Startup is off by default. Administrator windows may be skipped; some applications enforce minimum sizes. This first release has not been tested on every supported Windows version or monitor setup.
