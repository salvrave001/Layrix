# Layrix 1.0.3 — launch, editor chrome, and menus

This release makes a normal start open the editor, keeps autostart in the tray, and finishes the glass look on zone editing.

- Launching `Layrix.exe` opens the editor window. The Windows Startup shortcut still uses `--startup` and only shows the tray icon.
- If Layrix is already running, another double-click on the EXE opens the editor. An autostart launch does not steal focus.
- The on-desktop zone editor toolbar matches the rest of the app: blurred acrylic, dark pill buttons, and a light title icon. Save is no longer accent-colored.
- Zone number badges on the desktop use the same dark rounded style.
- Dropdown items in **Отображение зон** stay opaque so the hint text no longer shows through the list.

Close Layrix before replacing its files. Copy an existing `layouts.json` into the new folder. Check the Startup switch after moving the program.

The archive includes Windows App SDK and Visual C++ runtime DLLs. Extract it completely and keep the files together.

Запуск через exe открывает редактор; автозапуск по-прежнему только в трее. Панель правки зон на рабочем столе в том же стеклянном стиле, тёмные кнопки без синего «Сохранить». Пункты списка «Отображение зон» непрозрачные.

Перед заменой файлов закройте Layrix и перенесите `layouts.json`.
