# Layrix 1.0.4 — language, tray close, and custom layouts

This release adds English, keeps the editor as compact thumbnails, and makes the close button return to the tray.

- The title bar has a compact **RU / EN** menu. The choice is saved in `layouts.json` and applies to the editor, settings, tray menu, and zone-edit chrome.
- Layout cards stay thumbnail-sized and wrap into as many rows as fit the window instead of stretching across the gallery.
- Closing the editor window hides it to the notification area. Layrix keeps running; use **Выход** / **Exit** in the tray menu to quit.
- Right-click a custom layout to **Edit**, **Rename**, or **Delete**. Built-in templates still use the pencil, which creates a custom copy.

Close Layrix before replacing its files. Copy an existing `layouts.json` into the new folder. Check the Startup switch after moving the program.

The archive includes Windows App SDK and Visual C++ runtime DLLs. Extract it completely and keep the files together.
