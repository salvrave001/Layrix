# Layrix 1.0.2 — editor, snapping, and appearance

This release adds snap and color settings, three zone display modes, and a translucent glass editor.

- Snapping still happens only while you drag a window with the hold key. Zones are no longer painted all the time.
- **Отображение зон** is a dropdown with three modes: **Невидимые области**, **Зоны поверх**, and **Зоны на рабочем столе**. Hidden keeps snap without painting. On-top draws zones above other windows during the drag. On-desktop keeps them under regular windows.
- The snap-hold key is editable. The default remains Shift. Press the setting, then a key or combination; Esc cancels capture. Extra zones still use Ctrl, or Shift/Alt if Ctrl is already part of the hold chord.
- Zone highlight color and the app accent default to the Windows accent. Both can be set to a custom HEX/RGB color. The palette button opens a Blender-style picker (wheel, RGB, HSV, Hex) next to **Палитра**, above the editor.
- The editor uses a blurred acrylic backdrop and semi-transparent cards. Action buttons stay dark and no longer take the accent fill. Settings in the title bar is a gear icon only.

Close Layrix before replacing its files. If you already have a `layouts.json`, copy it into the new folder. The previous `showZonesOnTop` value is migrated: on becomes **Зоны поверх**, off becomes **Невидимые области**. Check the Startup switch after moving the program to another folder.

The archive includes Windows App SDK and Visual C++ runtime DLLs. Extract it completely and keep the files together.
